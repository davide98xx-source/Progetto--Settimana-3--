# Progetto--Settimana-3--

Progettazione di una libraria con:
Pulsante per cambiare tema da giorno a notte, con adeguato cambio di colore del testo, da nero a bianco e viceversa.
Barra di inserimento libri
Barra di ricerca
Pulsante di filtraggio dei libri da leggere
Pulsante di filtraggio dei libri letti
Contatore statico numerico dei libri totali
Contatore dinamico(Barra che si riempe) in base alla % di libri letti
